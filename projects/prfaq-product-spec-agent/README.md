# PRFAQ Product Spec Agent

`Python · product craft · AI`

This turns an early product brief into a customer promise, success measures, constraints, risks and unresolved questions.

I keep assumptions visible because early product documents can become misleading when uncertainty gets polished into confident language too soon.

## Run

```bash
python main.py
python main.py --test
```

A fuller version would connect to discovery notes, telemetry and decision records so the output can distinguish evidence, inference and open questions.
