# Career Discovery Ranking Study

`Python · product ranking`

A personal product study using LinkedIn career discovery as the surface. I am not affiliated with LinkedIn.

I wanted to test a ranking objective built around **career fit, growth, freshness and location** rather than raw engagement.

## Product question

Can a career surface optimize for qualified, durable fit without turning every interaction into a click or session-time objective?

The small ranking model makes the objective inspectable: skill fit carries the largest weight, then growth adjacency, freshness and location. The result includes the component scores rather than only a final rank.

## Run

```bash
python main.py
python main.py --test
```
