# Architecture Patterns Across the Ash Intelligence Lab

## Deterministic shell, probabilistic center
Use deterministic routing, permissions, state, budgets and audit around model reasoning.

## Evidence before autonomy
Grounding, evals, confidence and workflow completion determine whether the next state is **answer, review, fallback, or action**.

## Human review is a designed state
Human-in-the-loop is explicit in the state machine for consequential actions.

## End-to-end telemetry
Observe input → decision → action → outcome so teams can locate whether failure belongs to retrieval, model behavior, tools, workflow, controls or adoption.

## Reusable platform, legitimate variation
Provider onboarding, policy and workflow engines separate a common contract from regional, product or tenant variation.

## Product outcomes above vanity metrics
Evals should connect technical quality to completion, trust, adoption and measurable business impact.
